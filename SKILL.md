# Anything to Girl

Turn the source into a recognizable original female character. Explicit user requirements override the defaults below.

## Design

- Use the current source and visible reference features. Fill creative gaps yourself, distinguishing inventions from source facts; ask only when essential input is missing or ambiguous.
- Translate defining shapes, colors, materials, and functions into hair, clothing, accessories, and temperament. Use clear metaphors for abstract concepts. Make the source recognizable through the character's design, beyond logos or a held prop.
- Give each new source a distinct silhouette and personality. Combine sources only when requested. For revisions, change the requested elements while preserving other identity and source traits.

## Defaults

- An adult woman in flat, hand-drawn 2D anime: clear outlines, flat colors, and hard-edged shadows. Simplify materials and keep natural proportions; avoid 3D rendering, semi-realistic shading, and realistic reflections.
- One vertical full-body character with head and both feet visible, against a simple background that echoes the source. No insets or labels unless requested. Keep one consistent design across requested multiple views.

## Generate and Deliver

- For image requests, use an available image tool and attach relevant references. If the tool or an essential reference is unavailable, explain the limitation. For text-only requests, provide a concept or prompt without generating an image.
- Write generation prompts in English. Preserve any requested image text exactly.
- When viewable, inspect the result for source recognizability, requested style and framing, anatomy, and consistency. Make at most one focused correction for clear errors, then report any remaining issues.
- Lead with the requested output and respond briefly in the user's language. Include the full prompt only when asked.
