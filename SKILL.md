# 万物娘化

Create a beautiful, expressive adult female character rooted in the current source. Explicit user choices override defaults.

## Choose the task

- Personification or female redesign: retain distinctive source traits and choose a compelling whole-character idea. Compare ideas internally before generation.
- Style conversion or local edit: preserve the supplied character's identity and defining design. Reinterpret only what the request requires. A requested style governs the whole figure; chibi treatment changes the body and clothing shapes as well as the head.
- Assign each reference a role: source identity, illustration style or a specific shape preference. Use only its intended qualities. A reference sheet's layout does not prescribe the output layout.
- For discussion or prompt-only requests, give text. Use an available image tool for image requests.

## Art direction

- Default to refined hand-drawn 2D anime throughout the image: expressive lines, designed shadows, nuanced color and selected fine detail. Keep surfaces softly shaded with restrained sheen.
- For a new design, choose a fresh complete outfit for this character. Color, fabric, coverage, leg styling, boot height and heel shape have no preset. Favor personal style and coherent mixing. Preserve the existing outfit for style-only conversions unless changes are requested.
- For full proportions, keep visible leg silhouettes smooth and streamlined, with shallow calf curves, unobtrusive knees and little anatomical shading. Adapt these preferences to the requested stylization.
- Give the image a sense of place using a few readable background shapes and calm color relationships. Paint the setting economically with broad forms, restrained texture and quiet space. Concentrate fine detail and stronger contrast on the character. The background may stay loosely suggested while still conveying place and mood.

If a new concept repeats recent work, read [design-language.md](references/design-language.md) before generation.

## Output

- One adult character shown once, full body with the entire head and both feet visible, in an illustrated setting. No panels, inset portraits or extra views.
- Closed-toe footwear. Sandals and open-toe designs are excluded.
- Lettering is optional. Decide afresh whether it helps; keep any words brief, legible, artistically styled and visually secondary, clear of the character.

## Execute and stop

- Write a concise prompt for the current task, applying only relevant art preferences and the output requirements above. Use [image-prompts.md](references/image-prompts.md) if helpful; do not paste the whole guide into the prompt.
- Use only current source inputs and explicitly chosen references. For independent personifications, use fresh-generation controls when available. For conversions or edits, use the intended character as the reference/edit target. Skill invocation does not clear conversation history.
- Default to one finished image from at most one generation/edit call. Request one output using an exposed count control when available. After an image returns, inspect read-only, deliver once and stop. No automatic repaint, polish, repair or comparison version. A failure without an image is reported and stops the request. Additional calls require an explicit request; for multiple requested images, stay within that count.
- Keep replies brief and in the user's language. Report material shortcomings honestly. Do not redisplay an image already shown by the tool.
