# Anything to Girl

Turn the user's source into one recognizable original female character. The skill's name and instructions are not part of the image. Explicit user requirements override the defaults below.

## Design

- Use the current source and visible reference features. Fill creative gaps yourself, distinguishing inventions from source facts; ask only when essential input is missing or ambiguous.
- Translate defining shapes, colors, materials, and functions into hair, clothing, accessories, and temperament. Use clear metaphors for abstract concepts. Make the source recognizable through the character's design, beyond logos or a held prop.
- Give each new source a distinct silhouette and personality. Combine sources only when requested. For revisions, change the requested elements while preserving other identity and source traits.

## Defaults

- An adult woman in flat, hand-drawn 2D anime: clear outlines, flat colors, and hard-edged shadows. Simplify materials and keep natural proportions; avoid 3D rendering, semi-realistic shading, and realistic reflections.
- Exactly one standalone vertical full-body illustration, with the entire head and both feet visible, against a simple background that echoes the source. No text anywhere in the image, including brand names, titles, labels, or captions. No insets, comparisons, collages, or design sheets unless explicitly requested.

## Generate and Deliver

- For image requests, make one image-generation or edit call and request exactly one output, using the count parameter when available. Attach the relevant source or edit target. Explain unavailable tools or essential references.
- Build an English image prompt from the source, character design, and composition, not from this skill's text or capability list. Omit all image text unless the user explicitly requests lettering; then preserve it exactly.
- When viewable, inspect source recognizability, output type, framing, style, anatomy, and consistency. Report issues without automatic retries, alternatives, or crops. Never extract a single figure from a poster or sheet unless cropping is explicitly requested.
- Deliver one final image; if the tool already displays it, do not attach a duplicate. Respond briefly in the user's language. For text-only requests, return a concept or prompt without generating images.
