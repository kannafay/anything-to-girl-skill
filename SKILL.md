# Everything to Anime Girl

Imagine the source as a beautiful original adult anime woman. Guide the intended result while leaving visual invention to the image model. Explicit user choices take precedence.

## Understand the request

- Use the current source and its visible features. Each new source starts an independent character concept. Carry over an earlier character's identity or design only for a requested revision.
- Distinguish source/identity images from style references and rejected examples. A style reference guides illustration quality, not the character's appearance or outfit. Treat source facts separately from invented character traits.
- Choose creative defaults yourself. Ask only when essential source information is missing. For concept, analysis or prompt-only requests, give text; for image requests, use an available image-generation tool.

## Design priorities

- **Original concept:** imagine how the source's distinctive identity, meaning and character could become a person. Aim for a recognizable, inventive interpretation with its own personality and visual identity.
- **Appeal:** create a beautiful adult woman with presence, femininity and compelling personal style. Let her appearance, expression and fashion emerge from the concept.
- **Finish:** aim for refined, expressive 2D character illustration. Genshin Impact's official illustrations are a broad reference for polish and appeal, not a prescribed wardrobe or character template. Follow any user-specified art direction.
- **Creative freedom:** leave unspecified design decisions open. No default garment genre, hairstyle, footwear, hosiery, skin exposure or pose is required. Shared illustration quality should allow distinct character concepts.

Read [design-language.md](references/design-language.md) when the concept feels generic or too close to an earlier result.

## Output format

- One adult character shown once in a standalone full-body composition, with the entire head and both feet visible. Keep the background secondary to the character.
- No text anywhere, including clothes and props. No panels, inset portraits, extra views, turnarounds or collages. A style reference's layout does not change this format.

## Compose, generate and deliver

- Write a short English prompt around the source's identity, the creative goal and the required output format. Let the image model invent the visual design instead of prescribing a complete outfit in advance. Add concrete details only for explicit user choices or necessary source facts. Use [image-prompts.md](references/image-prompts.md) as a flexible starting point.
- Attach images relevant to the current request when supported and identify their roles. Use an earlier generation as an edit target only when revising that character. Generate the requested image count, defaulting to one. Keep replies brief and in the user's language; avoid duplicating an image already displayed by the tool.
- When viewable, check whether the concept feels original, recognizable, beautiful and well finished, and whether the output format is correct. Correct an obvious issue without redesigning unrelated parts. If generation is unavailable, explain the limitation.
